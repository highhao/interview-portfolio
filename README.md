# 技術作品集

以後端系統設計、外部 API 整合與資料處理自動化為主，整理專案流程、個人職責與架構設計。

## 專案案例

- **[產險投保平台｜車險與旅平險](https://github.com/highhao/insurance-saas-platform)**：多家保險公司 API 整合、投保流程與服務分工。
- **[多使用者遊戲操作平台](https://github.com/highhao/desktop-control-platform)**：多使用者授權、Web UI 與本機 Agent／Worker 協作。
- **[試算表專案追蹤同步](https://github.com/highhao/google-sheets-sync)**：多人資料同步與欄位衝突處理。
- **[酒類商品資料擷取](https://github.com/highhao/alcohol-product-scraper)**：靜態／動態來源擷取與商品欄位統一。
- **[Flask 電商網站](https://github.com/highhao/flask-ecommerce)**：商品、購物車、訂單與付款整合。
